# Organizar o Cérebro

O caminho é sempre este, e **cada degrau é um lugar de parar**:

1. `diagnosticar_nota` — o que está **ao alcance** do mentor. Não persiga pontos que
   dependem de ajuste nosso.
2. `triar_fila` — **o julgamento é seu**, e é a razão de você estar nesta conversa: onde o
   critério automático diz `passa`, decida você.
3. **Proponha uma seleção curta e pergunte.** Não siga sem resposta.
4. `propor_lote` com o que ele aprovou — mostre a consequência antes de qualquer escrita.
5. `reunir`, **um nome por vez**, só com `confirmado=True` depois do sim.

⚠️ **Se a seleção passar de uma dúzia, pare e mande para a tela.** Ontologia › Reunir o que
está espalhado faz o lote de uma vez, com desfazer para o lote inteiro. Duzentos nomes são
duzentos turnos, e a conversa é o lugar errado para isso.

Os critérios de aceitar ou rejeitar cada nome vêm na descrição de `triar_fila`; os três
tempos e os limites entre gestos estão em [[cuidar-do-cerebro]].
